## GitHub Pages
1. 新建一个 GitHub 仓库，将 `index.html`、`assets/` 和 `.nojekyll` 直接上传至仓库根目录。
2. 打开 Settings → Pages，在 Build and deployment 中选择 Deploy from a branch，并选择 main / root。
3. GitHub Pages 会生成一个 HTTPS 网址。

## 其他静态网站服务器
将 `index.html` 与 `assets` 文件夹放在站点根目录即可。网页使用相对路径，支持子目录部署。
